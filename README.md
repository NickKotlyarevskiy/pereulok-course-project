# Переулок

Учебный курсовой проект по дисциплине «Серверная веб-разработка». Сайт посвящён коротким городским прогулкам по Москве: каталог маршрутов, журнал заметок, расчёт примерной продолжительности и форма предложений.

## Технологии

- PHP 8.3 или новее;
- Laravel 13;
- Blade для серверных представлений;
- Eloquent ORM;
- SQLite по умолчанию; при необходимости можно переключить соединение на MySQL через `.env`;
- HTML, CSS и JavaScript.

## Требования к окружению

Нужны PHP 8.3+, Composer и стандартные расширения PHP, включая `mbstring`, `openssl`, `fileinfo`, `tokenizer`, `xml` и PDO. Для запуска с настройками по умолчанию требуется `pdo_sqlite`. При использовании MySQL потребуется `pdo_mysql` и настроенная база данных.

## Локальный запуск

Команды выполняются из корневой папки проекта:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000`.

## Основные разделы

- `/` — главная страница и подборка маршрутов;
- `/walks` — каталог с фильтрами по району, времени и сложности;
- `/walks/{slug}` — подробная карточка прогулки;
- `/journal` — статьи и заметки;
- `/journal/{slug}` — отдельная статья;
- `/estimate` — расчёт времени на основе длины маршрута, темпа и остановок;
- `/idea` — форма отправки предложения;
- `/about` — информация об устройстве проекта.

## Данные

Миграции создают таблицы `walks`, `articles` и `suggestions`. Команда `php artisan migrate --seed` добавляет демонстрационные маршруты и статьи. Повторный запуск сидера обновляет демонстрационные записи по `slug`, не создавая их дубликаты.

## Проверка

```bash
php artisan test
```

Feature-тесты проверяют открытие страниц, просмотр маршрута по `slug`, расчёт времени с параметрами URL и сохранение предложения в базе данных.

## Размещение на веб-сервере

Корневой каталог сайта веб-сервера должен указывать на папку `public`, а не на корень проекта. В `public/.htaccess` добавлены правила перенаправления запросов на `index.php` для Apache с включённым `mod_rewrite`. Для Nginx потребуется отдельная конфигурация виртуального хоста.

При публикации необходимо использовать production-значения `.env`: установить `APP_ENV=production`, `APP_DEBUG=false`, задать собственный `APP_KEY` и корректные параметры базы данных. Файл `.env` не следует помещать в репозиторий.

## Примечание

Маршруты и тексты в начальном наборе данных подготовлены для демонстрации функций учебного приложения. Перед использованием на местности следует проверить актуальную доступность проходов и территорий.
