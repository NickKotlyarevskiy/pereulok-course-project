# Переулок

Учебный курсовой проект по дисциплине «Серверная веб-разработка». Сайт посвящён коротким городским прогулкам по Москве: каталог маршрутов, журнал заметок, расчёт примерной продолжительности и форма предложений.

## Технологии

- PHP 8.3 или новее;
- Laravel 13;
- Blade для серверных представлений;
- Eloquent ORM;
- SQLite по умолчанию; при необходимости можно переключить соединение на MySQL через `.env`;
- HTML, CSS и JavaScript.

## Требования к окружению

Нужны PHP 8.3+, Composer и стандартные расширения PHP, включая `mbstring`, `openssl`, `fileinfo`, `tokenizer`, `xml` и PDO. Для запуска с настройками по умолчанию требуется `pdo_sqlite`. При использовании MySQL потребуется `pdo_mysql` и настроенная база данных.


## Основные разделы

- `/` — главная страница и подборка маршрутов;
- `/walks` — каталог с фильтрами по району, времени и сложности;
- `/walks/{slug}` — подробная карточка прогулки;
- `/journal` — статьи и заметки;
- `/journal/{slug}` — отдельная статья;
- `/estimate` — расчёт времени на основе длины маршрута, темпа и остановок;
- `/idea` — форма отправки предложения;
- `/about` — информация об устройстве проекта.

## Данные

Миграции создают таблицы `walks`, `articles` и `suggestions`. Команда `php artisan migrate --seed` добавляет демонстрационные маршруты и статьи. Повторный запуск сидера обновляет демонстрационные записи по `slug`, не создавая их дубликаты.
